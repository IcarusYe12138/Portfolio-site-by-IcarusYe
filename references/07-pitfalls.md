# 07 · 避坑清单（现象 → 原因 → 怎么避免）★

> 全部来自真实翻车。新站上线前与每次大改后，把本清单当 checklist 过一遍。

## 部署与缓存

### 1. 改了 CSS/JS 但线上「没生效」
- **现象**：新 HTML 结构 + 旧样式/行为混搭，页面错乱。
- **原因**：托管平台（CF Pages 等）对静态资源发 `immutable + 1y max-age`，URL 不变浏览器就永不再请求。
- **避免**：所有 CSS/JS 引用挂 `?v=YYYYMMDD`；**每次改内容必 bump**。可写个小脚本全站替换版本号。

### 2. 同一文件的多处编辑丢失
- **现象**：一次会话里对同一 HTML 改了三处，最后只剩一处（如字典某语言块丢失）。
- **原因**：并行/交叉编辑同一文件产生竞态，后写覆盖先写。
- **避免**：**同一文件的多处修改严格顺序执行**，一次编辑会话集中完成；AI 结对编程时尤其要防 agent 并行 Edit 同一文件。

### 3. 页面文件莫名膨胀（几百 KB 的 HTML）
- **现象**：index.html 从几十 KB 涨到几百 KB，混入陌生样式块（IDE 主题类名）、HMR 脚本、成片重复节点。
- **原因**：调试期浏览器 DOM 快照被回写到源文件；且会**复发**。
- **避免**：写清理脚本（按 id 删工具样式块、过滤垃圾行、清空装饰容器）；每次大改后 `wc -l` 抽查核心页面行数是否在正常区间。

### 4. 删除的文件线上还能访问
- **现象**：删掉的旧字体/图片，边缘节点仍短期返回 200。
- **原因**：CDN 边缘缓存 TTL 未到。
- **避免**：确认新代码已无引用即可，等 TTL 过期；不必强行「purge 成功」。

## 媒体

### 5. 网盘视频塞进 `<video>` 播不了
- **现象**：浏览器直接下载了文件，或 video 控件黑屏。
- **原因**：用的是**分享页 URL**（`dl=0`），不是流式直链。
- **避免**：直链加 `raw=1` 参数；确认托管方支持 HTTP Range（拖进度条的前提）。

### 6. iframe 嵌在线平台页被拦（ERR_BLOCKED_BY_RESPONSE）
- **现象**：iframe 区域空白，控制台报被响应头拒绝。
- **原因**：平台对裸 `/watch`、`/view` 页设了 X-Frame-Options / CSP frame-ancestors。
- **避免**：加平台约定的 `?embed` 参数（`/watch?embed`）；上线前实测。

### 7. 本地开发音视频控制台一堆 ERR_ABORTED
- **现象**：本地 `python -m http.server` 跑站，媒体元素报连接中断。
- **原因**：`preload="metadata"` 拉完元数据就掐断连接；且本地简易服务器无 Range 支持，日志更吵——**是环境问题，不是代码 bug**。
- **避免**：不用修代码；生产托管平台支持 Range，线上干净。判断标准：线上能不能播，而不是本地日志干不干净。

### 8. 上传大文件失败 / 部署被拒
- **现象**：视频 PDF 传不上去。
- **原因**：托管平台单文件上限（CF Pages 25 MiB）。
- **避免**：大媒体放对象存储，页面直链；页面层只留 HTML/CSS/JS/字体/海报/MP3。

### 9. 嵌入的媒体链接过阵子集体失效
- **现象**：昨天还好好的，今天 403。
- **原因**：对象存储**带签名的临时 URL** 有 TTL。
- **避免**：生产环境用长期有效的公开读配置或绑定自定义域名。

## 字体

### 10. 中文字体分片工具静默无产物 / 进程卡死
- **现象**：cn-font-split 跑完没有输出文件；或设小 chunkSize 后进程挂起被 SIGKILL。
- **原因**：① 该工具**不吃 woff2 输入**（必须 TTF/OTF）；② 小子集上 chunkSize 过小触发分包死循环；③ pyftsubset 产出的 CFF 若不 desubroutinize，下游子集器会卡死。
- **避免**：输入用 TTF/OTF；chunkSize 用默认值；中间产物做 desubroutinize。

### 11. 分片后字体内嵌清单正则清 `src:local(...)` 连 `src:` 一起吞
- **现象**：生成的 @font-face 非法，字体**静默回退**系统字体（不报错）。
- **原因**：正则贪婪匹配把属性名吞掉。
- **避免**：后处理脚本正则精确到 `local\([^)]*\)`；生成后浏览器 DevTools 检查实际命中字体族。

### 12. 全字库分片反而更慢
- **现象**：按整字库（9MB+/字重）分片后，页面命中海量小分片，总请求量和流量反升。
- **原因**：站内实际用字分散，每个字都拉自己所在分片。
- **避免**：**先按「站内实际字符集」子集化、再分片**——用脚本收集全站字符 → 子集化 → 分片；中文站字体载荷可砍半以上。

## 交互与兼容

### 13. 触屏设备图片永远是灰的
- **现象**：手机上看作品图全灰，无 hover 显色。
- **原因**：灰度滤镜依赖 hover，触屏无 hover。
- **避免**：`@media (hover:hover) and (pointer:fine)` 包住灰度规则；触屏默认彩色。

### 14. 语言切换动画把页面搞抖 / 被用户否掉
- **现象**：随机字符宽度不同导致布局跳；或全页扫描线/字符滚轮被用户明确否决。
- **原因**：切换期间元素宽度随字符变化重排；全页级动效喧宾夺主。
- **避免**：标题类用**锁宽解码**（冻结高度 + overflow:hidden）；正文瞬时替换；不做任何全页过渡。

### 15. 无限滚动条自己把自己暂停了 / 永远不恢复
- **现象**：marquee 自动滚一段时间就停；或拖完不恢复。
- **原因**：用 scroll 事件判断「用户在操作」——**自动滚动自己写的 scrollLeft 也触发 scroll 事件**，idle 判定永远失败；恢复定时器与持放逻辑打架。
- **避免**：idle 判定只监听**真实输入**（wheel / touchstart / pointerdown）更新时间戳；恢复用防抖定时器；hover 暂停做成多带联动计数（进 +1 出 -1）。

### 16. 无限滚动条在宽屏上中段露空隙
- **现象**：视口比「半份内容」宽，循环回卷处出现空白。
- **原因**：内容 ×2 的一半仍窄于视口。
- **避免**：JS 动态克隆内容直到 `scrollWidth/2 ≥ 视口宽 + 40`（设轮次上限）；克隆节点移除 `data-count` 等动画属性防重复触发。

### 17. iOS Safari 顶部出蓝边 / 导航毛玻璃异常
- **现象**：iPhone 上页面顶端一条异色边。
- **原因**：overscroll 橡皮筋露出了透明顶栏后面的背景。
- **避免**：顶栏**初始背景就设纯白**（不透明），滚动后再挂毛玻璃效果。

### 18. 逐行遮罩动画换行错乱、出「孤儿行」
- **现象**：英文段落某行只剩一个词，或 chip 被拆成单字盒。
- **原因**：拆行时用的是回退字体的度量，webfont 加载后实际换行变了；CJK/拉丁混排拆分粒度不对。
- **避免**：`document.fonts.ready` 与 `loadingdone` 后**重建一次行拆分**；行分组容差随行高缩放（带边框 chip 的盒顶偏移在容差内）；已展示过的段落重建时直接终态不重播。

### 19. 滚动隐藏的顶栏在 iOS 惯性滚动时不回来
- **现象**：滚到底顶栏/页脚不出现。
- **原因**：惯性滚动期间 scroll 事件停发。
- **避免**：对 footer 挂 IntersectionObserver 兜底（进入视口强制显示 chrome）。

### 20. iPad 等断点边缘设备布局错位
- **现象**：恰好 1024px 宽的设备（iPad Pro 竖屏/横屏）卡片错位、标题不对齐。
- **原因**：断点边界 + 高分屏缩放落在媒体查询夹缝。
- **避免**：平板断点用**更宽的 gutter**（`clamp(28px,5vw,64px)`）防贴边；对 1024px 档单独用 `@media` 微调；真机过一遍。

### 21. 章节网格基线对不齐
- **现象**：多列内容顶边参差。
- **原因**：`align-items:baseline` 在内容块高矮不一时顶边漂移。
- **避免**：结构化内容用 `align-items:start` 硬顶对齐。

## 流程

### 22. 「删掉」的需求只删了一半
- **现象**：用户要求删某功能，HTML 删了但 CSS/JS/字典 key 残留，甚至触发空引用。
- **避免**：删功能 = HTML 节点 + CSS 规则 + JS 逻辑 + 字典 key 四处同步删；删完控制台过一遍。

### 23. 快照保存的外链文章丢样式
- **现象**：本地存档页打开是裸 HTML。
- **原因**：另存时 CSS/字体/图片仍是外链绝对路径。
- **避免**：存档时把资源**全部落本地并改相对路径**；详见 `03-media-compat.md` 第三节。
