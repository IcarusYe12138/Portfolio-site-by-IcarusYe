# 00 · 首次接洽：问卷、素材与工具链

> **本 skill 被首次调用时，必须先走本流程**——先问清楚，再动手。宁可多问一轮，不要凭空假设用户的审美和内容。
> 黄金规则：**信息缺失时反问用户，不擅自代答。** 每个未回答的问题都可能变成后期的大返工。

## 一、风格接洽问卷（必须逐项问）

用户说「帮我做个作品集网站」时，第一轮对话只问风格与参考：

1. **你有没有代码参考？**（现成网站仓库、开源模板、以前的站点代码）
2. **你有没有网站截图？**（喜欢的网站、海报、品牌页的截图）
3. **你有没有 HTML 文件？**（旧站导出、原型页、半成品）
4. **你有没有图片或 Figma 之类的设计稿？**（情绪板、设计系统、Figma/Penpot 链接）

拿到任何一种 → 按 `01-design-and-style.md` 的「找风格三步法」走：参考素材 + 用户专业方向 → 风格 Demo → 书面设计规范。
什么都没有 → 引导用户口头描述 + 反面清单（「不要什么」往往比「要什么」更有用），先出一版风格 Demo 再对齐。

## 二、内容接洽问卷（第二轮，风格定了就问内容）

1. **简历是什么样的？** 教育背景、工作/实习经历、技能栈、语言——有没有现成 CV 文件？
2. **作品集是什么样的？** 有哪些作品、什么类型（影像/音频/网页/方案/设计）、每件作品有没有介绍文案？
3. **有没有包含所需要的链接？** 每件作品的外链（原始发布页、云盘直链、在线文档）是否齐全？**海外链接与内地链接是否都齐？**（双链路要求见 `03-media-compat.md`）

### 素材不全时的标准话术

如果作品链接/文件还没备齐：

> 链接和文件不齐没关系。我们可以**先做偏向设计风格的 Demo**（用占位内容把版式、配色、组件定下来），风格锁定后你再慢慢补传文件和链接，内容层最后填。

——顺序永远是：**风格 Demo 先行，内容后补**。不要等素材齐了才动工，也不要拿真内容去试错版式。

### 内容组织的推荐载体（引导用户三选一）

作品清单别散落在聊天记录里，引导用户集中记录在：

| 载体 | 适合 | 优点 |
|---|---|---|
| **飞书文档**（多维表格更佳） | 团队协作 / 手机随时改 | 结构化字段（作品名/类型/年份/海外链接/内地链接/简介）天然对齐双链路需求 |
| **详细 Markdown 文件** | 技术型用户 / 仓库党 | 可进 git、可 diff、可生成 |
| **Excel 表格** | 数据量大 / 表格控 | 列即字段，一行一作品 |

核心要求：**每件作品一行，链接列齐**（海外一列、内地一列），后续增删有据可查（配合 `10-content-ops.md`）。

## 三、工具链推荐（告知用户，不强制）

### 构建工具：优先推荐 TRAE（TraeCN）

官网：https://www.trae.cn/

推荐理由：
- **本地实时多设备预览**：手机 / 平板 / 桌面视口即时切换，做多模态适配非常直观——响应式断点（`05-structure-i18n.md` 的 4 断点体系）可以边改边看；
- 主流模型可选，代码质量与迭代效率有保障；
- 当然不限制其他工具——本 skill 的方法论与工具无关，任何 agent/编辑器都适用。

### 设计原型：网页视觉 Demo 首选 Kimi K3

介绍页：https://www.kimi.ai/blog/kimi-k3

推荐理由：审美水平在当前可用于网页设计的模型里足够好，适合承接「找风格三步法」第 2 步——把参考截图 + 用户气质描述喂给它，产出属于用户自己的风格 Demo（配色/字体/母题/版式）。
Demo 定稿后回到 TRAE 用本 skill 的组件规范落地代码。

**分工记忆口诀：Kimi 出审美，TRAE 出工程。**

## 四、隐私红线（每次接洽都要自检）

- 只问**建站必需**的信息；联系方式、真实姓名、证件号等敏感信息不主动索要，仅在用户自愿提供用于页面内容时接收；
- 用户提供的个人信息**只进站点项目**（本地/私有仓库），**绝不进本 skill 仓库**、不进文档示例、不进提交信息；
- skill 文档中的链接一律用 `overseas.example` / `mainland.example` 占位；
- 示例文案不使用可识别到具体个人的内容。

## 五、接洽完成判据（开工前 checklist）

- [ ] 风格输入确认（参考素材 ≥1 种，或明确「无参考、靠 Demo 对齐」）
- [ ] 语言需求确认（单语 / 双语 / 三语？——决定是否启用 `templates/trilingual.html`）
- [ ] 地域需求确认（仅海外 / 海外+内地双链路？——决定是否走 `03-media-compat.md`）
- [ ] 作品清单载体确认（飞书 / Markdown / Excel）
- [ ] 简历素材到位或已约定「后补」
- [ ] 工具链告知完毕（TRAE 构建 + Kimi K3 设计原型）
- [ ] 隐私红线自查通过

全部打勾 → 进入 `SKILL.md` 的「推荐工作流」第 1 步。
